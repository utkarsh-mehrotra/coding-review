Cycles, Ordering & Cloning

Dependency problems reduce to one question: is there a valid order, and if so what is it? A cycle means there is none. Course Schedule and Alien Dictionary differ only in how the edges get built.

QuestionTool
Is there a cycle in a directed graph?3-color DFS. An edge into a gray node (on the current path) closes a cycle.
Which nodes can never reach a cycle?Same colors. Nodes that finish black are safe (LC 802).
Give me a valid orderKahn's. Fewer than N nodes out means a cycle.
How many rounds if independent items run in parallel?Kahn's, one queue level per round.
Order inferred from sorted data (Alien Dictionary)One edge from the first differing character of each adjacent pair, then Kahn's. Watch the prefix case.
Deep-copy a graphMap old node to new node. The map doubles as the visited set.
