Disjoint Set Union / Union-Find

Manages partitions rather than traversing edges directly. Any problem with "connect/merge" operations interleaved with "are X and Y connected?" queries is DSU, not per-query BFS/DFS.

OperationComplexity
find() with path compressionO(α(N)) amortized
union() by rank/sizeO(α(N)) amortized

Primary uses: cycle detection in undirected graphs, connected-components queries, Kruskal's MST, offline queries, accounts-merge/equivalence-class problems.
