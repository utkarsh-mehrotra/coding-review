Strongly Connected Components, Bridges & 2-SAT

After Tarjan's/Kosaraju's, the usual follow-up is: collapse each SCC into a single node and build the condensation DAG — that's often the actual second half of the question.

Stack depth: the DFS in these templates is recursive, which is the form interviewers expect. On a chain around 105 deep it overflows Java's default stack, so the file includes a runWithBigStack helper that runs the call on a thread with a bigger one.
