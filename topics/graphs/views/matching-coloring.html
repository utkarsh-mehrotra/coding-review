Matching, Coloring & Functional Graphs

Three small patterns that don't fit elsewhere. Kuhn's is the matching algorithm you can actually write in 20 minutes. A functional graph is any structure where each node has exactly one outgoing edge, such as a next-pointer array.

PatternIdeaComplexity
Kuhn's matchingaugmenting DFS from each left node; Hopcroft-Karp (section 08) only for large inputsO(V·E)
k-coloringbacktrack node by node, reject a color a neighbor already has (k = 2 is the bipartite check)exponential
Floyd's cycle detectiontortoise and hare on next[]; a second pass from the start finds the cycle entryO(N), O(1) space
Longest cycle, functional graphtimestamp each walk; reaching a stamp from the same walk closes a cycle of length (time - stamp)O(N)
